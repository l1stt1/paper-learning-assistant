# 文献学习助手

在本机阅读 PDF、整理文章导读与概念、围绕原文提问，并按学习主题对照多篇文献。

程序可独立阅读和保存问题；Zotero 与模型服务都是可选功能。首次运行创建空文库，发行包不附带任何人的文献、笔记、问答或模型配置。

## 下载与启动

Windows 64 位用户请从 [Releases](https://github.com/l1stt1/paper-learning-assistant/releases) 下载最新预发布版。安装版提供本机启动器和桌面入口；便携版解压后运行 `PaperLearningAssistant.exe`。无需另外安装 Python、Codex 或 Zotero。

启动器显示服务状态及资料目录，可以打开阅读界面、创建备份、恢复到新资料目录和安全停止后台。关闭窗口时可以选择保留后台。模型请求仍在运行时，程序不会强制结束它。

初次使用可以直接导入 PDF，也可以打开本机 Zotero 后选择文献与附件。导入前核对标题和 DOI；导入不会自动发送论文给模型。扫描 PDF 可以显示，但当前不内置 OCR。

## 阅读与智能整理

- 单篇阅读包含原文、导读、概念和问答记录。点击原文页码可回到对应内容。
- 普通提问根据问题从整篇 PDF 中检索至多 6 页文字。阅读位置单独记录；选文、指定页和 Zotero 附件可以作为明确引用。原图只有主动勾选后才发送。
- “整理学习内容”会分批读取所选 PDF，并生成导读、概念和对照内容；已完成模块可续接，失败不会自动重试或切换服务。
- 主题可引用多篇文章。跨文学习需要明确选择文章集合，生成结果保留当时的范围。
- Zotero 导读保存是单独操作，需要 Zotero 原生授权；助手不自动同步修改原生笔记与批注。

模型生成内容可能有误，页码或摘录匹配也不代表解释已通过科学核查。关键结论请回到原文、图表与补充资料确认。

## 模型设置与隐私

在“模型设置”中选择本机 Codex CLI 或支持 Responses API 的 HTTPS 服务。API 凭据仅从用户已有环境变量读取，界面填写的是变量名称（默认 `OPENAI_API_KEY`），不接受密钥值，也不把密钥写进资料库。请通过自己的系统环境或秘密管理工具管理凭据。

主动生成时，所选论文文字、勾选的页图、问题及有限追问历史会发给所选服务。单篇解释还会附带已有本地笔记中最多 2,500 字符的摘要，界面会说明这一范围。跨文整理不附带个人笔记。付费与数据处理规则由用户选用的模型服务决定。

普通 PDF 阅读、导入、记录保存与备份不调用模型。服务仅监听本机回环地址，不提供多人服务器部署功能。资料与备份可能含私人文献和记录，分享前需要自行检查；备份 ZIP 不加密。

## 资料、备份与升级

程序目录与资料目录分开。默认资料位于 Windows 用户的本地应用数据目录；启动器可查看确切位置。`--data-dir` 指定的是**完整文库根目录**，其中包含文章清单、PDF、导读、学习数据库、主题、来源关联与运行材料。

备份前程序需处于空闲状态；启动器会安全停止服务，完成备份后重新启动。恢复先显示备份摘要，目标必须是新建或空目录，原文库不会被覆盖。备份包含实际引用的外部论文文件，并在备份内使用可迁移的路径。恢复后须在“模型设置”核对服务地址、模型和凭据变量并保存，再启用智能生成。历史开发备份与测试目录不纳入文库备份。Zotero 外部附件需要仍可在本机 Zotero 访问；已经导入助手的阅读 PDF 随备份保存。未保存的浏览器草稿不属于磁盘备份。

升级请先创建完整备份，再安装新程序版本。新版本继续使用同一资料目录；旧程序文件保留，方便回退。首次公开版本的数据格式标记为 1。将来若数据格式需要变更，会单独说明支持范围和迁移方式。不要让不同版本同时打开同一文库。

从早期定制版升级时，包含 `articles.json` 的原目录可作为完整文库原位接入，不要求搬走原论文与记录。早期 `--data-dir` 仅表示学习记录子目录；新版本不再沿用该含义，请传入包含 `articles.json` 的文库根目录。

## 从源码运行

要求 Python 3.11 或更高、PyMuPDF 及 Tkinter（原生启动器）。源码服务可直接运行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python launcher.py
```

只运行后台服务可使用 `python server.py --data-dir <完整文库目录> --port 18766`。API Key 不应写进脚本、命令参数、仓库或配置文件。Codex CLI 走现有登录；程序不替用户安装或登录模型客户端。

## 验证和构建

```powershell
python -m unittest discover -s tests
node --test tests/test_pdfjs_filename.mjs
python -m pip install -r requirements-build.txt
python scripts/build_release.py --output <新的输出目录>
```

测试使用合成 PDF 和模拟模型/Zotero，不需要私人论文、账号或付费调用。PDF.js 文件名回归检查需要 Node.js 22.13 或更高版本；运行应用本身不需要 Node.js。构建从明确文件清单选择程序与文档，排除个人文库及开发运行目录；构建脚本拒绝覆盖已有产物。

首版定位为 Windows 预发布版。Windows 本机验证不能替代所有硬件、杀毒软件和企业策略下的兼容测试。macOS/Linux 源码路径已有适配，但当前未承诺桌面安装支持。安装包暂未代码签名，Windows 可能显示未知发布者提示；请核对官方发布页和文件摘要，不要关闭系统安全功能。
